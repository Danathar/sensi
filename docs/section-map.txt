# Docs section map: every section of every tracked documentation page, and
# whether a test reads it.
#
# A page is listed here as [path]. Under it, every `##` and `###` heading of
# that page, written exactly as the page writes it, followed by one indented
# line:
#
#   joined: tests/<file>   that test reads what this section states
#   prose: unchecked: ...  the section states facts about the machine (a
#                          workflow, the settings file, the code, a pinned
#                          value) that no test reads; each is a candidate for
#                          a join test, and writing one turns the row joined:
#   prose: narrative: ...  the section states no such fact
#
# tests/test_docs_section_map.py fails when a tracked page has a heading with
# no row here, when a row names a heading the page no longer has, or when a
# joined: test does not exist or never opens the page. It does not prove any
# sentence true. What it changes is that a section of claims nothing checks is
# a visible `prose: unchecked:` line in the diff that adds it, instead of the
# silent default.
#
# Tracked pages: every tracked Markdown file at the repository root and in
# docs/ (not its subdirectories), plus docs/agent-tasks/README.md,
# docs/metrics/README.md and .github/copilot-instructions.md. A new page in
# one of those places has to be added here in the change that adds it.
